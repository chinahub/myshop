# 架构与结构

## 工作区布局（monorepo，共用远程仓库 chinahub/myshop）

```
E:\myshop_workspace                ← git 仓库根（远端 github.com/chinahub/myshop）
├── myshop-backend/                ← 后端工程（原 myshop 文件夹更名，Maven 多模块）
│   ├── myshop-common              纯 JDBC 工具类 SqlScriptRunner（无框架依赖）
│   ├── myshop-manager             ★ 后端主体（唯一有业务代码的模块）
│   │   ├── pojo                   实体：@TableName/@TableId/@TableField（列名尾下划线）
│   │   ├── dto                    ShopResult/ShopQueryResult/ShopTxResult + ItemCategoryDto + mall/*（校验注解）
│   │   ├── mapper                 Mapper 接口，extends BaseMapper<T>（无 XML）
│   │   ├── service-interface      服务接口（含 com.rocket.myshop.exception 商城业务异常）
│   │   ├── service                实现：@Service + @Transactional + LambdaQueryWrapper（含 mall/*）
│   │   └── web (jar)              ManagerApplication + 控制器（含 controller/mall/*）+ 全局异常 + 静态资源
│   ├── myshop-user                占位骨架（用户明确留作二期用户端服务，无代码）
│   ├── myshop-parent              历史遗留目录（未清理）
│   ├── ui-front / ui-bak          历史静态模板（商城图片素材来源），保留未迁移
│   ├── android-client / weixin-client  空壳占位
│   ├── dev/                       本地联调脚本（h2-init.sql、mall-seed.sql、MySQL 备份）
│   ├── 项目文档/                  myshop-manager.sql（建表脚本）+ 需求文档
│   └── pom.xml
├── myshop-manager-ui/             ← 后台管理前端（React18 + Vite + Antd，原 myshop-ui 移出）
├── myshop-mall-ui/                ← 商城前端（React18 + Vite，2026-10-15 新建）
├── docs/                          ← 本项目文档目录
└── start.bat                      一键启动后端 jar（需 JDK 25 与本地 MySQL）
```

依赖链：web → service → mapper / service-interface → pojo / dto。Maven 集团 `com.rocket.shop`，版本 0.0.1-SNAPSHOT。

## 部署形态（一个 jar、三个入口）

| 路径 | 内容 | 构建来源 |
| --- | --- | --- |
| `/` | 手写门户页（链接两个入口） | `myshop-manager-web/src/main/resources/static/index.html`（纳入版本管理） |
| `/admin/` | 后台管理 SPA | `myshop-manager-ui npm run sync` → `static/admin/` |
| `/mall/` | 商城 SPA | `myshop-mall-ui npm run sync` → `static/mall/` |
| `/items/** /users/** /mall/**` 等 | REST API | 后端控制器 |

要点：

- Summer 静态托管把以 `/` 结尾的路径映射到目录下 `index.html`（`/admin/` → `static/admin/index.html`），天然支持子路径部署。
- SPA 路由均为 HashRouter（Summer 不支持 `/**` catch-all 回退）。
- 两个前端 sync 脚本只清空各自子目录（`static/admin/`、`static/mall/`），互不影响门户页。
- 商城商品图位于 `myshop-mall-ui/public/images/`，构建后随 dist 同步到 `static/mall/images/`；数据库 `img_logo_` 存 `/mall/images/<文件名>`，开发与生产均为可直达 URL。

## 商城后端代码布局

```
com.rocket.myshop
├── domain        MallUser / MallCart / MallOrder / MallOrderItem
├── dto.mall      RegisterRequest / LoginRequest / LoginResult / CartAddRequest / CartUpdateRequest
│                 CartItemView / OrderCreateRequest / OrderView / OrderItemView
├── mapper        Mall*Mapper × 4
├── service       MallAuthService / MallCatalogService / MallCartService / MallOrderService（接口）
├── service.impl  对应实现；业务异常 MallAuthException(401)/MallNotFoundException(404) 在 service-interface 模块
├── controller.mall  MallAuthController(/mall/auth) / MallItemController(/mall/items)
│                    MallCartController(/mall/cart) / MallOrderController(/mall/orders)
└── exception     GlobalExceptionHandler：校验 400+violations；MallAuthException→401；MallNotFoundException→404
```

登录态：登录/注册发 UUID token，内存 ConcurrentHashMap 保存（重启失效），前端请求头 `X-Mall-Token` 携带。密码 `SHA-256(salt+password)` 十六进制存储。
