# 数据库设计

- 生产建表脚本：`myshop-backend/项目文档/myshop-manager.sql`（MySQL，InnoDB/utf8，列名尾下划线）
- H2 本地联调：`myshop-backend/dev/h2-init.sql`（MySQL 模式，幂等）
- 商城种子：`myshop-backend/dev/mall-seed.sql`（幂等，含建表兜底）
- 冒烟测试内联 schema：`ManagerSmokeTest.initH2Schema()`（H2 Regular 模式，`GENERATED BY DEFAULT AS IDENTITY` 替代 AUTO_INCREMENT）

**改表时三处同步**（见快速开始）。

## 后台管理表

### shop_item（商品）
| 列 | 类型 | 说明 |
| --- | --- | --- |
| id_ | int PK AUTO | 主键 |
| title_ | varchar(100) NOT NULL | 商品标题 |
| sell_point_ | varchar(500) | 卖点 |
| price_ | decimal(10,2) | 价格 |
| num_ | int | 库存 |
| barcode_ | varchar(40) | 条形码 |
| img_logo_ | varchar(500) | 主图地址（商城商品存 `/mall/images/<文件名>`） |
| status_ | char(1) '1'/'0' | 1 在售 0 下架（软删除） |
| create_time_ / update_time_ | datetime | 时间戳 |
| seller_id_ | varchar(40) | 商家 ID |
| item_category_name_ / item_brand_name_ | varchar(40) | 冗余类别/品牌名（有索引，便于查询） |
| sale_clients_ | varchar(100) | 销售渠道 |

### shop_item_category（商品类别，树形）
| 列 | 说明 |
| --- | --- |
| id_ / name_ / status_ | 主键 / 名称 / 1 正常 0 删除 |
| parent_id_ | 父类别（null = 一级） |
| level_ | tinyint 层级（1 一级，2 二级） |
| sub_category_num_ | 子类别计数（增删时维护） |
| items_num_ / rank_ | 预留 |

### shop_item_brand（商品品牌）
id_ / name_ / logo_ / status_(tinyint) / 时间戳。重名在 service 层拒绝。

### shop_menu（后台菜单）
id_ / name_ / code_ / parent_id_ / url_ / status_(tinyint) / 时间戳。前端菜单尚未消费（预留）。

### shop_user（后台用户）
userid_(PK varchar) / username_ / password_(密文) / op_date_。**商城不用它**。

### demo
演示表（id_ / name_），冒烟测试数据源。

## 商城表（2026-10-15 新增）

### mall_user（商城会员）
| 列 | 类型 | 说明 |
| --- | --- | --- |
| id_ | int PK AUTO | 会员 ID |
| username_ | varchar(40) UNIQUE | 用户名 |
| password_ | varchar(64) | SHA-256(salt+password) 十六进制 |
| salt_ | varchar(32) | 每用户随机盐 |
| nickname_ | varchar(40) | 默认同用户名 |
| status_ | tinyint(1) | 1 正常 0 禁用 |
| create_time_ / update_time_ | datetime | |

注意：password/salt 不出现在任何对外 DTO。

### mall_cart（购物车）
| 列 | 说明 |
| --- | --- |
| id_ | PK |
| user_id_ / item_id_ | 联合唯一（uk_mall_cart_user_item），重复加购合并数量 |
| num_ | 数量（1-99） |
| create_time_ / update_time_ | |

### mall_order（订单）
| 列 | 说明 |

### mall_order_item（订单明细快照）
| 列 | 说明 |
| --- | --- |

## 关键设计决定

1. 商品与类别/品牌用**名称冗余列**关联（item_category_name_/item_brand_name_），避免跨表 join，与 2016 原始设计一致；类别/品牌改名不会历史同步。
2. 库存扣减为事务内 select-then-update，适合演示场景；生产应改 `UPDATE shop_item SET num_=num_-? WHERE id_=? AND num_>=?` 条件更新。
3. token 存内存 ConcurrentHashMap：重启失效（玩具级会话），如需持久化可加 token 表。
4. `tinyInt1isBit` 陷阱见快速开始第 4 条。
