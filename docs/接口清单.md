# 接口清单

全部为 REST JSON 接口，基址 `http://localhost:8080`。管理语义接口前缀 `/items`、`/users`；商城接口前缀 `/mall/*`。鉴权仅商城接口需要（`X-Mall-Token` 请求头）。

## 统一返回格式

- 列表：`ShopQueryResult { total, list, start, length, queryParam, version, success }`
- 事务操作：`ShopTxResult { message, reasons{字段→原因}, version, success }`（HTTP 200 + success=false 表示业务失败）
- 校验失败：HTTP 400 + `{ status, error, violations: ["..."] }`
- 商城业务异常：`MallAuthException` → HTTP 401 + RestError{code,message}；`MallNotFoundException` → HTTP 404 + RestError
- 其他异常：HTTP 500 + RestError

## 后台管理接口

### 商品 `/items`
| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | ---|
| POST | /items/listItem.json | body `{start,length,...}` | 商品分页列表 |
| GET | /items/detail.json | `?id=` | 商品详情 |
| POST | /items/addItem | body Item | 新增（标题非空校验） |
| POST | /items/updateItem | body Item | 更新 |
| POST | /items/deleteItem | `?id=` | 软删除（status→0） |

### 品牌 `/items`
| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | --- |
| POST | /items/listItemsBrand.json | body `{start,length}` | 品牌分页 |
| POST | /items/addItemsBrand.json | body ItemBrand | 新增（重名拒绝） |
| POST | /items/updateItemsBrand.json | body ItemBrand | 更新 |
| POST | /items/deleteItemsBrand.json | `?id=` | 软删除 |

### 类别 `/items`
| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | --- |
| POST | /items/listItemsCategory.json | body `{start,length,name?,level?}` | 分页 |
| POST | /items/getSubItemsCategory.json | `?parentId=` | 子类别 |
| POST | /items/addItemsCategory.json | body @Valid ItemCategoryDto | 新增（同步父类计数） |
| POST | /items/updateItemsCategory.json | body @Valid ItemCategoryDto | 更新 |
| POST | /items/deleteItemsCategory.json | `?categoryId=` | 软删除 |

### 其他
| GET | /users/{username} | 路径变量 | 后台用户 |

## 商城接口 `/mall/*`

登录态：除 register/login 外均需请求头 `X-Mall-Token`（登录/注册返回的 token）。

### 认证 `/mall/auth`
| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | ---|
| POST | /mall/auth/register | body `{username 3-40, password 6-40, nickname?}` | 注册即登录，返回 `{token,userId,username,nickname}` |
| POST | /mall/auth/login | body `{username,password}` | 登录发 token；用户名/密码错误、禁用 → 401 |
| POST | /mall/auth/logout | header token | 登出（幂等） |
| GET | /mall/auth/me | header token | 当前用户（不含密码哈希） |

### 浏览 `/mall/items`（公开）
| GET | /mall/items/list.json | `?start&length&keyword&itemCategoryName&itemBrandName` | 只出上架商品，按 id 倒序 |
| GET | /mall/items/detail.json | `?id=` | 上架商品详情（下架 → 404） |
| GET | /mall/items/categories.json | - | 两级类别树 `[{id,name,children:[{id,name}]}]` |
| GET | /mall/items/brands.json | - | 在售品牌列表 |

### 购物车 `/mall/cart`（需登录）
| GET | /mall/cart/list.json | - | 条目视图（标题/价格/主图/库存实时值） |
| POST | /mall/cart/add | body `{itemId, num 1-99}` | 重复加购合并数量；超库存失败 |
| POST | /mall/cart/updateNum | body `{cartId, num 1-99}` | 改数量（校验库存与归属） |
| POST | /mall/cart/delete | `?cartId=` | 删除条目 |

### 订单 `/mall/orders`（需登录）
| POST | /mall/orders/create | body `{consigneeName, consigneePhone, consigneeAddress}` | 从购物车整单下单：写快照明细、扣库存、清购物车。事务：任一商品下架/库存不足整体失败。返回 `{orderId, orderNo, totalAmount}` |
| GET | /mall/orders/list.json | `?start&length` | 我的订单分页（含明细） |
| GET | /mall/orders/detail.json | `?id=` | 订单详情（校验归属） |
| POST | /mall/orders/pay | `?id=` | 模拟支付：仅待付款→已付款，记录 payTime |
| POST | /mall/orders/cancel | `?id=` | 取消：仅待付款可取消，回补库存 |

订单状态：1 待付款 / 2 已付款 / 3 已取消。

## 例子（curl）

```bash
# 注册并拿 token
TOKEN=$(curl -s -X POST http://localhost:8080/mall/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"demo1","password":"123456"}' | python -c "import sys,json;print(json.load(sys.stdin)['token'])")

# 加入购物车
curl -s -X POST http://localhost:8080/mall/cart/add \
  -H "Content-Type: application/json" -H "X-Mall-Token: $TOKEN" \
  -d '{"itemId":32,"num":1}'

# 提交订单
curl -s -X POST http://localhost:8080/mall/orders/create \
  -H "Content-Type: application/json" -H "X-Mall-Token: $TOKEN" \
  -d '{"consigneeName":"王五六","consigneePhone":"13800000000","consigneeAddress":"北京市朝阳区示例路 1 号"}'
```
